# Repository instructions

Before investigating, editing, or reviewing this project, read and follow
`CLAUDE.md` in the project root.

Keep this `AGENTS.md` local. Do not force-add, commit, or push it to GitHub.

## Scope

- Work in `onplay-stt`; do not apply Glotalk's Android, Gradle, Compose or AIDL
  conventions to this project.
- Verify the current source and build configuration before documenting commands
  or claiming a feature works.
- Keep changes focused and preserve existing user work.
- Do not commit downloaded runtimes, model archives, extracted models or build
  output. Check ignore rules before staging them.
